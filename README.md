# PrețRadar – suport

PrețRadar este o aplicație iOS care urmărește prețurile produselor tale preferate de pe evomag.ro și îți arată imediat când se ieftinesc.

## Cum funcționează

PrețRadar se conectează la un server mic care rulează pe calculatorul tău, în rețeaua Wi-Fi de acasă. Serverul verifică prețurile de 3 ori pe zi (08:00, 14:00, 20:00) și păstrează istoricul. Aplicația îți arată prețul curent, diferența față de verificarea anterioară, stocul și graficul de evoluție.

1. Pornești serverul PrețRadar pe calculator (Windows, macOS sau Linux, cu Python 3).
2. În aplicație, la **Setări**, introduci adresa afișată de server, de exemplu `http://192.168.1.100:8000`.
3. Apeși **+** și lipești linkul unui produs de pe evomag.ro.

Nu ai încă un server? Alege **„Încearcă modul demo”** la prima pornire sau activează **Setări → Mod demo**, ca să vezi aplicația cu produse de exemplu.

## Suport

Pentru întrebări, probleme sau ca să primești serverul PrețRadar, scrie-ne la **puiutpavel@gmail.com**. Răspundem de obicei în 1–2 zile lucrătoare.

**Aplicația nu găsește serverul?** Verifică să fie calculatorul pornit, serverul deschis, telefonul pe aceeași rețea Wi-Fi și ca rețeaua să fie setată ca „Privată” în Windows.
